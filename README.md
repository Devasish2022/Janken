## 🧠 Overview

A browser-based implementation of the traditional **Janken (Rock–Paper–Scissors)** game featuring:

- 🎯 First-to-5 competitive scoring system  
- 🧠 Dual difficulty AI (Random + Predictive Counter Logic)  
- 🎬 Modal-based win/lose end screen  
- 🔊 Interactive sound feedback (Win / Lose / Click)  
- 🌙 Dark mode toggle  
- ✨ Smooth UI animations & thinking effect  
- 📱 Mobile + Desktop responsive layout  

All game logic, state handling, and UI interactions are implemented manually without external libraries.

---

## ⚙️ Tech Stack

- HTML5  
- CSS3 (Flexbox, Animations, Media Queries)  
- Vanilla JavaScript (ES6)  
- Vercel (Deployment)

---

## 🧠 AI Logic (Hard Mode)

In **Hard Mode**, the computer predicts the player’s last move and selects the counter move instead of choosing randomly.  
This demonstrates basic adaptive AI behavior and conditional logic control.
